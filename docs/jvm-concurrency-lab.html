📚 Glossário rápido
Virtual Thread: thread leve gerenciada pela JVM.
Carrier Thread: platform thread na qual uma Virtual Thread é montada para executar.
Race condition: resultado depende da ordem imprevisível das execuções concorrentes.
Deadlock: ciclo de espera em que ninguém consegue progredir.
Semaphore: mecanismo que limita quantas tarefas podem acessar um recurso ao mesmo tempo.
Atualização Java 24/25: bloquear dentro de synchronized deixou de causar o pinning clássico de Virtual Threads com o JEP 491. No Java 25, pinning continua relevante principalmente em chamadas native e foreign functions.
